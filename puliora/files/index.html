Puliora › Files & batch

Clean hidden characters in files

Drop one file or select several at once. Puliora cleans them on your device, checks that their structure is unchanged and gives you a report for each one.

  • Runs locally
  • Nothing uploaded
  • No account
  • Free

Supported formats and checks

FormatWhat is checked
JSONParses before and after; structure (keys, arrays, types) must be identical. A JSON file that failed to parse because of a BOM or a no-break space becomes valid.
CSV / TSVSame number of rows and fields per row, quoted fields included. The UTF-8 BOM that Excel expects is kept by default.
HTML / XMLTag sequence unchanged; XML must stay well-formed. Escaped invisible entities such as &#8203; are reported.
SRT / VTTSame number of cues and timing lines.
TXT, Markdown, codeMarkdown hard line breaks and code layout are preserved; only characters change.
DOCXOnly the text runs of the document, headers, footers, notes and comments change; every other part of the file is copied byte for byte, and each modified part must be well-formed XML.

Files are never re-formatted: Puliora edits characters in place and then validates. Encoding is detected (UTF-8, UTF-16 with or without BOM); files that are not valid UTF-8 are read as Windows-1252 and saved as UTF-8, with a warning.

PDF is not supported

Copy the text out of the PDF and use the PDF text fixer instead.

Limits

Up to 25 MB per file and 200 files per batch, processed one by one in the background so the page stays responsive; you can stop at any time. Results stay in this tab's memory until you download them or close the page.

Frequently asked questions

Are my files uploaded?

No. Files are read and cleaned in your browser: the page cannot make network requests, and the background worker that cleans the files has its network functions disabled.

Will it change the formatting of my Word document?

No: only text characters inside runs change. Styles, images and layout are copied unchanged.

Why isn't PDF supported?

Reliable PDF text extraction needs a full PDF engine; copy the text and use the PDF text fixer.

How large can a file be?

25 MB per file and 200 files per batch.

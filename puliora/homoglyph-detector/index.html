Homoglyph detector

“pаypal” and “paypal” look identical, but the first contains a Cyrillic а. Puliora finds letters from another script hidden inside words and suggests the letter they imitate.

What are homoglyphs?

Different characters that look the same: Latin a and Cyrillic а, Latin o and Greek ο, Latin e and Cyrillic е. Unicode publishes an official list of confusable characters in Technical Standard #39; Puliora uses that data (current version, bundled with the page) to name the letter each one imitates.

Where they are used

  • Phishing links and fake brand names (“аpple”).
  • Variable names and identifiers in code reviews.
  • Getting around keyword filters and moderation.

Legitimate mixed scripts

A Russian word in an English sentence is not an attack, and neither is Japanese mixing kanji and kana. Puliora flags only words that mix scripts with look-alike letters, never whole foreign words, and in Safe mode it only reports: replacement happens in Strict mode or when you choose it, with a preview.

See also the invisible text detector and the Unicode inspector.

Frequently asked questions

What is a homoglyph attack?

Using look-alike characters from another script to imitate a word, a domain or an identifier.

Can it check domain names?

Yes, paste the address or the text containing it. Each look-alike letter is listed with its code point and the Latin letter it imitates.

Why doesn't it auto-fix everything?

Because mixed scripts can be legitimate. Safe mode reports; Strict mode replaces only inside mixed-script words.

Which Unicode data does it use?

confusables.txt from UTS #39 and the Unicode 18.0 script data, bundled with the page.

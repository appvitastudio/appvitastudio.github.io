Non-breaking space remover (NBSP and U+202F)

No-break spaces look exactly like spaces, but software treats them as different characters. Puliora replaces them with normal spaces — never deletes them — and keeps them where typography uses them on purpose.

When to keep them

In Safe mode Puliora keeps no-break spaces in two recognised typographic positions: between digits (10 000) and before French punctuation or inside guillemets (« Merci ! »), plus between a number and a currency or percent sign. Everywhere else they are replaced with a normal space. Strict mode replaces all of them.

Word, Excel and SQL

Spreadsheet TRIM functions and simple SQL trims often remove only the normal space U+0020, so values with NBSP stay “different”. Cleaning the exported CSV with the file cleaner fixes the values while checking that rows and columns are unchanged.

Frequently asked questions

How do I remove non-breaking spaces in Word?

Copy the text here, clean it and paste it back — or clean the exported text file with the file cleaner.

Why doesn't TRIM remove spaces in Excel?

TRIM removes the normal space character; a no-break space (U+00A0) is a different character. Cleaning the data replaces it with a normal space.

What is U+202F?

The narrow no-break space: a thinner space that also prevents line breaks, used in French and in number grouping.

Will it break French typography?

Not in Safe mode: spaces before ; : ! ? and inside « » are kept. Strict mode replaces them if you prefer plain spaces.

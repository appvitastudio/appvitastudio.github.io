The same deterministic engine behind the cleaner, for code reviews, data pipelines and LLM applications.

Developer mode

Open the Unicode inspector for code points, UTF-16 offsets, UTF-8 bytes, escapes in six notations and a JSON report with an exact change log. Pick Source code as format to also report escaped invisible characters such as "\u200B".

Chrome extension

Right-click selected text and choose Clean with Puliora, or clean the clipboard from the toolbar popup. It asks for these permissions only (the list is read from the extension's manifest when this page is built):

  • activeTab — access to the current tab only after you click the toolbar button or the context menu item
  • clipboardRead — reads the clipboard only when you click Paste & clean clipboard in the popup, never in the background
  • contextMenus — adds Clean with Puliora to the right-click menu for selected text
  • scripting — reads the selected text in the tab where you invoked the extension (together with activeTab)
  • storage — keeps your settings in the browser

There are no host permissions, so it can read a page only after you click it, and it never sends text anywhere. Status: built and tested, not yet published on the Chrome Web Store.

Threats worth filtering

  • Trojan Source: bidi overrides and isolates that make code render differently from how it compiles — reported as high severity with unbalanced-control detection.
  • Prompt injection in tag characters and data in variation selectors — decoded (details).
  • Homoglyph identifiers — mixed-script words (details).

Rules and versioning

Every rule has a stable ID (for example zwsp, bidi-override, tag-hidden) and a documented default per preset; reports include the engine version and the Unicode data version. See the rule list.

Frequently asked questions

Is there a REST API?

Not yet. It is implemented and tested locally but not deployed; this page will say so when it is available.

What does the extension access?

Only the selection of the tab where you invoke it, after your click, and the clipboard only when you press Paste & clean clipboard. It stores only its settings. No host permissions.

How are rules versioned?

Rules have stable IDs; reports state the engine version and the Unicode data version used.

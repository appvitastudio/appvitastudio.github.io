Unicode inspector

See exactly what a string contains: offset, code point, official name, general category, script, UTF-8 and UTF-16 bytes. Invisible and unusual characters are highlighted.

  • Runs locally
  • Nothing uploaded
  • No account
  • Free

Reading the table

  • Offset is the position in UTF-16 code units, the unit JavaScript, Java and C# use for string indexes.
  • Category is the Unicode General Category: Lu/Ll letters, Mn combining marks, Zs spaces, Cf format characters (most invisible ones), Cc controls, Co private use, Cn unassigned.
  • Script is the writing system (Latin, Cyrillic, Arabic…); Common and Inherited characters are shared by several scripts.
  • UTF-8 shows the bytes a file would contain; a lone surrogate is invalid and cannot be encoded.

Developer tools in the same view

Escape invisible characters as JavaScript, JSON, Python, HTML, CSS or U+ notation, decode escapes back into characters, and download the full analysis as JSON with an exact change log. Data: Unicode 18.0.0, see data sources.

Frequently asked questions

How do I find the code point of a character?

Paste it: the table lists the U+ code point and the official name of each character.

What do the category codes mean?

They are Unicode General Categories: for example Cf format, Zs space separator, Mn nonspacing mark.

Which Unicode version is used?

Unicode 18.0.0, from the official Unicode Character Database files.

Can I export the results?

Yes, as JSON, CSV, Markdown or a printable HTML report.

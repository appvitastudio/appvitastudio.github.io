Invisible text detector

Text can carry a whole message that no one sees: instructions for an AI assistant, a tracking code, a secret. Puliora finds these payloads, decodes them as inert text and removes them.

ASCII smuggling with tag characters

The Unicode block U+E0000–U+E007F contains invisible copies of every printable ASCII character. Most apps do not draw them, but language models read them. In 2024 the security researcher Johann Rehberger showed how such hidden text can steer AI assistants and recommended filtering these characters on input and output. Puliora decodes any tag-character text it finds and shows it as plain text — it is never executed or sent anywhere. The only legitimate use, subdivision flags such as 🏴 England, is recognised and kept.

Emoji smuggling with variation selectors

There are 256 variation selectors. In 2025 Paul Butler documented how to encode arbitrary bytes as a string of selectors after a single emoji: the emoji looks identical and the data survives copy-paste. A base character can legitimately carry only one selector, so Puliora flags every extra one and decodes the bytes when they form readable text.

Zero-width steganography

Strings of two or four different zero-width characters can encode binary data. Puliora reports long runs as possible hidden data and attempts the common decodings. A failed decoding proves nothing: other schemes exist, and the characters are removed either way.

Why this matters for LLM apps

If you build with language models, filter hidden characters from user input, retrieved documents (RAG) and model output. The developer tools and the Chrome extension help in day-to-day work; look-alike letters are covered by the homoglyph detector.

Hidden text in PDFs

PDF files are not opened directly. Copy the text from the PDF and paste it here: hidden characters are copied with it.

Frequently asked questions

What is ASCII smuggling?

Hiding readable text with Unicode tag characters, which are invisible to people but readable by software and language models.

Can emoji hide data?

Yes: variation selectors appended to an emoji can encode arbitrary bytes. Puliora detects and decodes this.

Does it detect hidden text in PDFs?

Paste text copied from the PDF; the PDF file itself is not parsed.

Is the decoded text sent anywhere?

No. Decoding happens on your device and the result is displayed as plain text.

Does it detect AI-written text?

No. It finds characters, not authors.
